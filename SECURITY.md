# Segurança / Security

Para relatar uma vulnerabilidade do HeartWire, envie uma descrição e passos mínimos para **[fernandosaito@hotmail.com.br](mailto:fernandosaito@hotmail.com.br)**. Não publique chaves privadas, áudio ou detalhes de exploração em uma issue pública. O mantenedor é [saitofernando](https://github.com/saitofernando). Não há prazo de resposta garantido.

For a HeartWire vulnerability, send a description and minimal reproduction steps to **[fernandosaito@hotmail.com.br](mailto:fernandosaito@hotmail.com.br)**. Do not publish private keys, audio or exploit details in public issues. The maintainer is [saitofernando](https://github.com/saitofernando). No response deadline is guaranteed.

- [Modelo de segurança e privacidade — PT-BR](docs/pt-BR/seguranca.md)
- [Security and privacy model — English](docs/en/security.md)

O app destina-se a redes locais confiáveis. HTTPS e validação de origem não autenticam individualmente os aparelhos. / The app is intended for trusted local networks. HTTPS and origin validation do not individually authenticate devices.
